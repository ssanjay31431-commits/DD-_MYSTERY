# Photos Directory

Place your personal photos here:
- `hero.jpg`
- `story.jpg`
- `timeline1.jpg`
- `timeline2.jpg`
- `photo1.jpg`
- `photo2.jpg`
- ...

You can easily update the photo paths at the top of `script.js` inside the `birthdayData` object:

```javascript
const birthdayData = {
  girlfriendName: "HER NAME",
  yourName: "SANJAY",
  heroPhoto: "assets/photos/hero.jpg",
  ...
};
```
